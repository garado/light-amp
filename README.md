# Amp

My personal fork of [Sublunarian's](https://github.com/sublunarian) [Amp](https://github.com/sublunarian/amp), a Subsonic-compatible music player for the Light Phone III.

Full credit to Sublunarian and other Amp contributors!

Main changes in this fork:
- Support ratings from 0-100 (I run a patched Navidrome server allowing 0-100 ratings)
- Clientside playlist folders
- UI adjustments to make it as close as possible to the stock LightOS music player
